# UI 设计规范

## 设计语言

采用 macOS 26 **Liquid Glass** 设计语言，核心特征：
- 半透明玻璃材质，有深度感和层次感
- 光影在表面流动的微动效
- 跟随系统浅色/深色模式自动适配
- 不使用自定义主题色，依靠系统材质本身呈现

## 面板规格

| 属性 | 值 |
|------|-----|
| 宽度 | 360pt |
| 高度 | 500pt（最大） |
| 背景 | `.glass` 材质 |
| 圆角 | 16pt（面板外围） |
| 阴影 | 系统默认 depth 阴影 |

## 搜索栏

| 属性 | 值 |
|------|-----|
| 高度 | 36pt |
| 背景 | `.glassEffect(.regular.interactive(), in: Capsule())`，直接作用于搜索栏内容布局 |
| 圆角 | 胶囊形 |
| 左右边距 | 12pt |
| 顶部边距 | 12pt |
| Placeholder | "搜索..." |
| 图标 | 左侧放大镜 SF Symbol |

- 使用原生 SwiftUI TextField + FocusState，焦点与选中外观使用同一状态，不单独维护“展开”标记。
- 聚焦时轻微放大至 1.025 倍、上浮 2pt，增强系统玻璃交互和阴影；失焦时约 0.25 秒恢复。减少动态效果时不缩放或上浮。
- 点击放大镜或搜索栏进入编辑；点击列表、按钮、空白等搜索栏外区域退出焦点并恢复外观，不清空搜索文字或过滤结果。点击外部时不拦截原来的按钮/复制动作。
- 清空搜索按钮仅清除关键词；关闭面板、切换设置、打开清除确认时退出搜索编辑。

## 历史卡片

| 属性 | 值 |
|------|-----|
| 背景 | 透明，内容直接显示在面板玻璃背景上，不叠加独立磨砂矩形 |
| 圆角 | 不设置条目背景圆角 |
| 边距 | 水平 12pt，垂直 6pt（卡片间距） |
| 内边距 | 12pt |
| 最小高度 | 52pt |

### 文字卡片
- 左侧：文字预览，最多 2 行，SF Pro 正文，lineLimit(2)
- 右侧：相对时间标签 + 置顶图标按钮 + 删除图标按钮
- 文字颜色：primary（系统标签色）

### 图片卡片
- 左侧：图片缩略图，40×40pt，clipped，圆角 6pt
- 缩略图右侧：文字标签"图片"或图片尺寸信息
- 右侧：与文字卡片相同的操作按钮布局

### 置顶卡片
- 通过系统强调色的 `pin.fill` 标识置顶，仍保持透明条目背景
- 置顶条目保持在列表最上方

## 操作图标

| 功能 | SF Symbol |
|------|-----------|
| 置顶/取消置顶 | `pin.fill` / `pin` |
| 删除 | `trash` |
| 搜索 | `magnifyingglass` |
| 设置 | `gearshape` |
| 状态栏图标 | `clipboard` 或自定义 |

置顶和删除按钮使用 28×28pt 的圆形交互式 Liquid Glass 背景，采用 plain 按钮样式，避免系统默认矩形按钮外框；保留无障碍标签、键盘交互及帮助提示。删除图标使用系统红色，并标记为 destructive 操作。

## 清除确认弹层

- 使用面板内 SwiftUI 弹层，不使用带应用/文件夹图标的系统 NSAlert。
- 宽度 300pt，内边距 20pt，24pt 圆角，`.glassEffect(.regular)` 液态玻璃背景。
- 仅显示标题、不可撤销及保留置顶记录的说明、取消和清除按钮；按钮为右对齐的 64×28pt 胶囊，间距 10pt，字号 12pt。使用 plain 样式叠加中性 Liquid Glass，不铺满整行；清除保持 destructive 语义，仅文字红色，不给背景添加红色 tint。
- 显示/关闭使用约 0.25 秒轻量弹簧淡入缩放，减少动态效果时仅淡入淡出；与主面板的系统 Popover 动画独立，不叠加额外内容入场动画。
- 展示时禁用底层内容，避免误触；Escape 和点击遮罩取消，默认焦点在取消按钮，不默认回车删除；关闭面板时重置确认状态。

## 底部状态栏

- 半透明分隔线（`.separator` 材质）
- 左侧：条目计数文字（如"共 23 条"），SF Pro 脚注，secondary 颜色
- 右侧：设置按钮（齿轮图标），点击切换到设置视图

## 设置页

- 设置页滚动区域向右扩展 12pt，滚动内容保留 12pt 右侧边距，使滚动条位于外侧留白区域；内容宽度与对齐不变，避免滚动时覆盖文字和按钮。
- 左上角返回按钮为 28×28pt 圆形交互式 Liquid Glass，使用 plain Button 和 Circle 命中区域，与列表圆形操作按钮保持一致。
- 保留时长用三个独立、等宽的交互式 Liquid Glass 按钮（1 天 / 3 天 / 5 天），横向占满内容宽度，间距 10pt、高度 38pt、圆角 12pt，不使用不透明 segmented Picker 底色。
- 选中项使用系统强调色文字和轻量玻璃染色（12% 强调色），保持玻璃质感；提供选中状态无障碍标识。
- Bundle ID 多行输入隐藏 TextEditor 默认滚动内容背景，不使用 Liquid Glass、高光或交互材质；采用系统 primary 色 4% 透明度浅底、10% 透明度的 0.5pt 细边框，12pt 圆角、8pt 内边距、72pt 编辑区高度，避免纯白底板。等宽 caption 字体和系统 primary 文字颜色适配浅色/深色模式；边框不拦截输入点击。

## 颜色

- 不指定固定颜色值
- 所有元素使用系统语义色（primary, secondary, .separator 等）
- Liquid Glass 材质自动适配系统外观
- 强调色：系统默认蓝色（用于操作按钮的 active 态）；破坏性操作（删除/清除）使用系统红色

## 动效

- 面板弹出/收起：启用系统 NSPopover 动画，点击菜单栏图标打开、再次点击关闭和点击外部 transient 收起均走原生动画；不叠加额外的内容淡入缩放。在 willShow 时开始后台加载历史，避免等待显示完成后再加载
- 置顶/取消置顶：约 0.32 秒轻量弹簧重排，图标使用系统 symbol replace 过渡；以稳定记录 ID 保持条目身份。
- 单条删除：约 0.22 秒向右滑出并淡出，其余条目平滑补位。
- 确认清除：约 0.28 秒非置顶条目轻微缩小并淡出；置顶条目保留并补位，清空时空态淡入。列表保持挂载，支持删除最后一条时的退出动画。
- 搜索过滤：无动画（直切结果，保持性能）；首次加载、分页及普通后台刷新不套用操作动画。
- 操作动画在存储提交成功、后台分页结果应用时触发，不通过睡眠延迟数据操作。减少动态效果时只做约 0.15 秒淡入淡出，不滑动、缩放或替换图标动效。

## 字体

全部使用系统 SF Pro，不自定义：
- 正文：`.body`
- 时间标签：`.caption`
- 搜索框：`.body`
- 计数：`.caption`
