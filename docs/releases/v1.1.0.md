## 本次更新

- 历史内容直接显示在面板背景上，移除逐条磨砂矩形；置顶、删除和返回按钮采用圆形液态玻璃，删除仅图标为红色。
- 恢复面板弹出/收起动画，并增加置顶重排、删除退出和确认清除动画；减少动态效果时采用轻量淡入淡出。
- 搜索栏采用交互式液态玻璃；点击其他区域退出焦点、恢复外观，保留关键词和搜索结果。
- 清除确认改为无应用图标的玻璃弹层，使用紧凑按钮、中性背景和红色清除文字；置顶记录不会被清除。
- 设置页采用等宽玻璃保留天数按钮；Bundle ID 输入区使用低对比底色和细边框，滚动条不再覆盖正文区域。
- 增强后台分页、过时搜索取消、缩略图缓存、图片删除补偿和剪贴板失败处理。
- 增加暂停采集、前台应用排除及敏感标记过滤，改进登录项状态和面板生命周期处理。

## 下载与安装

- **系统要求：macOS 26 或更高版本。**
- 下载 `HistoryClipboard-v1.1.0-universal.zip`，解压后将 `HistoryClipboard.app` 放入「应用程序」目录，再打开应用。
- 安装包为 Universal，包含 **Apple Silicon（arm64）和 Intel（x86_64）**；`SHA256SUMS.txt` 可用于核验下载文件。
- 升级沿用已有剪贴板历史和保留设置，无需清空数据库。

## 首次打开与隐私说明

安装包采用本地 ad-hoc 签名，**未经过 Apple 公证**。若 macOS 提示无法验证开发者，请先确认下载来自本仓库，再到「系统设置 → 隐私与安全性」查看「仍要打开」选项；也可以从源码使用 Xcode 自行构建。

内容只在本地保存，但数据库和图片未加密。未标记的密码仍可能被记录；应用排除按采集时的前台应用判断，不保证识别后台复制来源。
